# 第三局 · 网页游戏试玩

HTML / JavaScript 静态游戏，可通过 GitHub Pages 在线试玩。

## 发布

在仓库 Settings → Pages 中选择 Deploy from a branch，分支选择 main，目录选择 / (root)，保存后等待部署完成。

根目录包含 `.nojekyll`，用于保留时间线关卡的 `2_1` 目录。请保留所有素材的文件名大小写和目录结构。

游戏进度保存在玩家当前浏览器的 localStorage 中。清理浏览器数据或更换域名、设备后，进度不会同步。

当前版本已压缩图片及剧情视频，保留完整素材和场景。GitHub Pages 在中国大陆的访问效果仍需使用实际网络测试。
